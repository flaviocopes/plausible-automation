# Agent guide

This repository operates analytics configuration and stores credentials
locally. Read the [Security](README.md#security),
[Architecture](README.md#architecture), and
[Technical decisions](README.md#technical-decisions) sections of `README.md`
before modifying it.

## Layout

The code sits at the repository root:

- `install.sh` copies the skill and the CLI into place.
- `setup-plausible/SKILL.md` is the Codex skill.
- `setup-plausible/agents/openai.yaml` is the skill's interface metadata.
- `setup-plausible/scripts/plausible-setup` is the Python CLI.
- `setup-plausible/scripts/plausible-keychain-store` is the Expect helper.
- `tests/` holds the unit tests.
- `README.md` holds all the documentation.

## Verification

From the repository root:

```bash
python3 -m py_compile setup-plausible/scripts/plausible-setup
python3 -m unittest discover -s tests -v
```

Tests must use a fake local server and isolated configuration. Never point an
automated test at a real Plausible instance.

## Invariants

- Never hardcode a Plausible origin or tracked website domain.
- Never print, log, commit, or pass a password or token in process arguments.
- Keep login, Stats API, and per-site plugin secrets in separate Keychain items.
- Keep `setup --dry-run` available before project edits.
- Treat property creation, tracker insertion, and goal creation idempotently.
- Refuse to add a second analytics tracker when an existing integration needs
  human review.
- Require an exact goal ID and `--yes` before goal deletion.
- Never delete or rotate an API key automatically.
- Do not use or suggest Plausible's Sites API.
- Keep configuration examples developer-owned and placeholder-only.

## Source boundaries

`setup-plausible/scripts/plausible-setup` owns CLI parsing, dashboard form
automation, API requests, project inspection, and formatting.
`setup-plausible/scripts/plausible-keychain-store` is a small Expect bridge for
secrets generated by Plausible itself. `setup-plausible/SKILL.md` owns agent
behavior and should remain concise.

Update tests, `README.md` (including the [changelog](README.md#changelog)),
`setup-plausible/agents/openai.yaml`, and the version together when a public
command or workflow changes.
